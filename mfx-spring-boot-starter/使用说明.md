# mfx 开放 API 调用说明（给对接方）

本文说明如何用 **mfx-spring-boot-starter** 调用开放接口。服务端使用 **国密 AK/SK（HMAC-SM3）** 鉴权，SDK 会自动算签，调用方**不要**自己拼 Header。

当前提供 **2 个接口：GET、POST**。

---

## 1. 环境与凭证

向接口提供方确认以下信息（测试环境示例，以实际下发为准）：

| 项 | 示例值 |
| --- | --- |
| Base URL | `http://172.16.22.148:8080` |
| Access Key（AK） | `demo-ak-001` |
| Secret Key（SK） | `a8f3K9mQx2Vp7nR4wYcE6uHt1bZs0Ld9` |

- **SK 仅保存在你们服务端配置里**，不要写进前端、不要提交公开仓库。
- 时钟尽量与服务器同步（签名带时间戳，偏差过大请求会被拒）。

## 2. 引入 SDK

### 2.1 Maven 仓库（Nexus Snapshots）

```xml
<repositories>
  <repository>
    <id>nexus-snapshots</id>
    <url>http://10.126.138.142:8081/nexus/content/repositories/snapshots</url>
    <snapshots><enabled>true</enabled></snapshots>
    <releases><enabled>false</enabled></releases>
  </repository>
</repositories>
```

### 2.2 依赖

```xml
<dependency>
  <groupId>com.mfx</groupId>
  <artifactId>mfx-spring-boot-starter</artifactId>
  <version>0.0.1-SNAPSHOT</version>
</dependency>
```

建议使用方 Spring Boot **3.2.x**。

若 Nexus 需要登录，在本机 `~/.m2/settings.xml` 配置与仓库 `id` 一致的 `<server>`（账号找提供方或运维）。

## 3. 配置（application.yml）

```yaml
mfx:
  enabled: true
  base-url: http://172.16.22.148:8080
  access-key: demo-ak-001
  secret-key: a8f3K9mQx2Vp7nR4wYcE6uHt1bZs0Ld9
  connect-timeout: 5s
  read-timeout: 10s
```

`base-url` / `access-key` / `secret-key` 必须与第 1 节一致。

## 4. 接口清单

统一响应壳：

```json
{ "code": 0, "message": "ok", "data": { ... } }
```

`code == 0` 表示成功；鉴权失败多为 `code: 401`。

### 4.1 GET：回显

| 项 | 说明 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/open/echo` |
| Query | `name`（可选，默认 `hello`） |

**SDK 调用：**

```java
@Autowired
private MfxApiService mfxApiService;

String json = mfxApiService.get("/api/open/echo", Map.of("name", "world"));
```

成功时 `data` 示例：

```json
{
  "method": "GET",
  "name": "world",
  "client": "demo-client",
  "serverTime": "2026-09-16T..."
}
```

### 4.2 POST：提交消息

| 项 | 说明 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/open/message` |
| Body | JSON：`title`（必填，≤64）、`content`（必填，≤512） |
| Content-Type | `application/json` |

**SDK 调用（字符串 body）：**

```java
String body = "{\"title\":\"ping\",\"content\":\"hello-from-sdk\"}";
String json = mfxApiService.post("/api/open/message", body);
```

**或传对象（由 SDK 序列化为 JSON 再签名发送）：**

```java
record Message(String title, String content) {}
String json = mfxApiService.post(
    "/api/open/message",
    new Message("ping", "hello-from-sdk"),
    String.class
);
```

成功时 `data` 示例：

```json
{
  "method": "POST",
  "title": "ping",
  "content": "hello-from-sdk",
  "client": "demo-client",
  "acceptedAt": "2026-09-16T..."
}
```

## 5. 完整调用示例

```java
import com.mfx.service.MfxApiService;
import org.springframework.stereotype.Service;
import java.util.Map;

@Service
public class OpenApiDemoService {

    private final MfxApiService mfxApiService;

    public OpenApiDemoService(MfxApiService mfxApiService) {
        this.mfxApiService = mfxApiService;
    }

    public void callGetAndPost() {
        // GET
        String echo = mfxApiService.get("/api/open/echo", Map.of("name", "world"));
        System.out.println("GET => " + echo);

        // POST
        String created = mfxApiService.post(
                "/api/open/message",
                "{\"title\":\"order\",\"content\":\"create-001\"}"
        );
        System.out.println("POST => " + created);
    }
}
```

无需手动设置 `X-Access-Key` / `X-Signature` 等 Header，Starter 已封装。

## 6. 联调自检

1. `curl http://172.16.22.148:8080/api/health` 能通  
2. 配置好 `mfx.*` 后启动你们的 Spring Boot  
3. 先调 GET，再调 POST；看返回 `code` 是否为 `0`  
4. 故意改错 `secret-key`，应得到签名失败 / 401  

不带签名直接访问（应失败）：

```bash
curl -s "http://172.16.22.148:8080/api/open/echo?name=x"
```

## 7. 常见问题

| 现象 | 可能原因 |
| --- | --- |
| 连接失败 | Base URL / 端口 / 网络不通 |
| 缺少鉴权头 / 401 | 未用 SDK，或 Starter 未生效 |
| 签名校验失败 | SK 与服务端不一致，或改了 path/query/body 未走 SDK |
| 请求已过期 | 本机时间与服务器差太大 |
| 依赖拉不下来 | Nexus 仓库 / 账号未配置 |

更完整的 Starter 说明见同目录 [README.md](README.md)。
